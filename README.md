AI Pantry Chef 
An AI-powered recipe generator that turns your fridge leftovers into master dishes. Built with **React** and **FastAPI**, using the **Qwen 2.5 LLM** via Hugging Face.

Features
* **Real-time AI Generation**: Suggests recipes based on user-inputted ingredients.
* **Full-Stack Architecture**: React (Frontend) + FastAPI (Backend).
* **Modern UI**: Clean, responsive, and minimalist design.

Tech Stack
* **Frontend**: React.js, Tailwind CSS
* **Backend**: Python, FastAPI, Uvicorn
* **AI**: Hugging Face Inference API (Qwen 2.5 Model)

Installation
1. Clone the repo: `git clone https://github.com/YOUR_USERNAME/ai-pantrychef.git`
2. Install Python dependencies: `pip install fastapi uvicorn huggingface_hub`
3. Install Frontend dependencies: `cd frontend && npm install`
4. Add your Hugging Face Token in `main.py`.
5. Run the app!
